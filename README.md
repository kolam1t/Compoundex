# Compoundex — Country & Geopolitical Risk Predictor

**Risk area:** Country & Geopolitical Risk
**Fintech idea:** Compoundex — investing education platform

Machine-learning model deployed as a web application with an HTML front end and a
JSON API.

**Live application:** `https://arsenddnv.pythonanywhere.com`

---

## 1. The Fintech idea

**Compoundex** teaches students and young investors how to value real companies the way
professionals do — building full discounted cash flow (DCF) valuations, following a live
model portfolio, and developing the analytical skills needed for a career in finance, at
a price a student can afford.

Tagline: *The Roots of Investment Discipline*

## 2. The machine-learning problem

Every DCF requires a discount rate, and for any company with material operations abroad
that discount rate must include a **country risk premium**. Students routinely get this
wrong — either ignoring country risk entirely or applying an arbitrary number — and the
error can swing a valuation by tens of percent. The live model portfolio carries the
same exposure, since its holdings operate across many jurisdictions.

**Problem:** predict whether a country will experience **elevated geopolitical risk over
the next 12 months** — sovereign stress, conflict escalation, a major sanctions action
or a disorderly political transition — severe enough that a valuation of a company
exposed to that country should carry a raised country risk premium.

The prediction is surfaced inside Compoundex's DCF tool: when a student values a company
exposed to a flagged country, the platform prompts them to widen the country risk
premium, and the same signal drives a review of the model portfolio's geographic
exposure.

| | |
|---|---|
| **Population** | Countries where companies in the Compoundex curriculum and model portfolio have material operations, observed annually |
| **ML task** | Binary classification (logistic regression) |
| **Target** | `elevated_country_risk` — 1 if a materially adverse geopolitical event occurs in the next 12 months, 0 otherwise |

### Input variables

| Variable | Type | Description |
|---|---|---|
| `sanctions_events_last_5_years` | Discrete | Distinct international sanctions actions against the country in the last five years |
| `sovereign_cds_spread_bps` | Continuous | 5-year sovereign CDS spread in basis points — the market's own price of default risk |
| `political_stability_index` | Continuous | World Bank WGI political stability scale, −2.5 (fragile) to +2.5 (very stable) |

The three variables triangulate country risk from independent angles: political
(stability index), market-priced (CDS spread) and diplomatic (sanctions history). This
matters because any single measure can be slow or distorted — CDS spreads react quickly
but are noisy, governance indices are robust but published with a lag.

## 3. The data

`fintech.xlsx` holds **1,000 synthetic country-year observations** generated by
`train_model.py` with a fixed seed (`np.random.seed(42)`), so the dataset is identical
on every run. The target is generated from a known logistic function of the three
predictors, so the relationship is real and the model has genuine signal to learn.
Base rate of elevated risk: **40.0%**.

## 4. Model performance

Logistic regression, 70/30 stratified train/test split.

| | Accuracy | Precision (class 1) | Recall (class 1) | F1 (class 1) |
|---|---|---|---|---|
| **Train** | 0.75 | 0.73 | 0.60 | 0.66 |
| **Test** | 0.71 | 0.67 | 0.53 | 0.59 |

Train and test scores are close, so the model is not overfitting.

```
sanctions_events_last_5_years    +0.3907
sovereign_cds_spread_bps         +0.0050
political_stability_index        -1.1030
intercept                        -2.0943
```

The signs are all as theory predicts: sanctions history and wider CDS spreads raise the
probability of elevated risk, political stability lowers it. The negative coefficient on
stability confirms the model learned the direction of the relationship rather than
fitting noise.

Recall on the elevated-risk class is 0.53, the expected limitation of a three-variable
linear model on a partly unpredictable outcome. In use the probability matters more than
the binary label — the application shows a probability and a risk band, and asks the
student to widen the country risk premium proportionally.

## 6. Setup instructions

### Run locally

```bash
git clone https://github.com/kolam1t/compoundex.git
cd compoundex
pip install -r requirements.txt
python train_model.py      # regenerates fintech.xlsx and fintech.joblib
python app.py              # serves at http://127.0.0.1:5000
```

### Deploy on PythonAnywhere

1. Open a **Bash console** and clone the repository:
   ```bash
   git clone https://github.com/kolam1t/compoundex.git
   ```
2. Install the dependencies:
   ```bash
   pip install --user -r compoundex/requirements.txt
   ```
3. On the **Web** tab: **Add a new web app** → **Manual configuration** → Python 3.10+.
4. Open the **WSGI configuration file** and replace its contents with
   `wsgi_pythonanywhere.py`, changing `arsenddnv` to your username.
5. Set **Source code** to `/home/arsenddnv/compoundex`.
6. Click **Reload**. The app is live at `https://arsenddnv.pythonanywhere.com`.

If the site errors, open the **Error log** on the Web tab — a missing package or a wrong
path in the WSGI file causes almost every failure.

## 7. API documentation

### `POST /api/predict`

Scores one country.

**Request**

```json
{
  "sanctions_events_last_5_years": 3,
  "sovereign_cds_spread_bps": 330.5,
  "political_stability_index": -1.2
}
```

**Response** `200 OK`

```json
{
  "prediction": 1,
  "label": "elevated_country_risk",
  "probability": 0.886,
  "risk_band": "High",
  "guidance": "Apply a substantial country risk premium and review portfolio exposure.",
  "inputs": {
    "sanctions_events_last_5_years": 3,
    "sovereign_cds_spread_bps": 330.5,
    "political_stability_index": -1.2
  },
  "model": "logistic_regression"
}
```

`prediction` is the binary class (1 = elevated risk). `probability` is the probability of
class 1, between 0 and 1. `risk_band` maps that probability to Low / Moderate / Elevated
/ High, with `guidance` describing the country risk premium action.

**Example request**

```bash
curl -X POST https://arsenddnv.pythonanywhere.com/api/predict \
  -H "Content-Type: application/json" \
  -d '{"sanctions_events_last_5_years": 3, "sovereign_cds_spread_bps": 330.5, "political_stability_index": -1.2}'
```

```python
import requests

r = requests.post(
    "https://arsenddnv.pythonanywhere.com/api/predict",
    json={
        "sanctions_events_last_5_years": 3,
        "sovereign_cds_spread_bps": 330.5,
        "political_stability_index": -1.2,
    },
)
print(r.json())
```

**Errors** — `400 Bad Request` when a field is missing or non-numeric:

```json
{ "error": "Missing required fields", "missing": ["sovereign_cds_spread_bps"] }
```

### `GET /api/health`

Returns service status, whether the model loaded, and the expected feature names.

| HTML form, non-numeric input | Validation message shown, no crash |
| `POST /api/predict` valid payload | `200`, probability 0.886, band High |
| `POST /api/predict` low-risk payload | `200`, probability 0.0319, band Low |
| `POST /api/predict` missing field | `400`, missing fields named |
| `POST /api/predict` non-numeric | `400`, numeric error returned |
| `GET /api/health` | `200`, model loaded |
| Public URL from a separate machine | Page served correctly |

The model is retrained on the deployment host, so `fintech.joblib` in this repository
was produced by the same script and the same seed as the deployed model and carries
identical coefficients.
